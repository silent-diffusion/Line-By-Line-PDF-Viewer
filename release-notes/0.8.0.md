## Line by Line 0.8.0

- **Dark theme.** Line by Line now follows Windows' light or dark app mode by default, and switches the moment you change it. Choose Light or Dark yourself in the new **Settings → Appearance** section. Pages stay white either way.
- **Second shortcuts for the number pad.** Every action can have a second shortcut. The defaults are `Ctrl+Alt+Num +` to highlight, and `Ctrl+Alt+Num 2` and `Ctrl+Alt+Num 8` to move the band. Change or remove them in Settings → Hotkeys; Backspace removes one.
  - Why not the number-pad period? It's the same key as Delete, so Windows reads `Ctrl+Alt+Num .` as Ctrl+Alt+Delete before any app can see it. `Ctrl+Alt+.` on the main keyboard still highlights.

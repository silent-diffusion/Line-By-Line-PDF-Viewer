## Line by Line 0.5.0

The first release with an installer. Download **LineByLine-win-Setup.exe** below and run it. It installs for your Windows user, with no admin prompt, and adds a Start menu shortcut.

- **Installer and updates:** Settings → Updates checks GitHub for new versions, shows what's new, and updates and restarts in one click. Turn on **Automatic updates** to check every time the app opens.
- **Value Grab** (off by default): shows each highlighted line's dollar amount; `Ctrl+Alt+C` copies it for Excel.
- **OCR** for scanned PDFs and images (PNG, JPG, TIFF, BMP), using the OCR built into Windows.
- **Column focus:** narrow the band to some columns and it steps only through matching table rows, across pages.
- Focus band with dimming, global `Ctrl+Alt+↑/↓` hotkeys, and layouts for landscape and portrait monitors.

The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

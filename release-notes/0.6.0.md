## Line by Line 0.6.0

- **Auto grab:** turn it on in Settings → Value Grab and the value is copied every time the band moves. Press `Ctrl+Alt+↓`, switch to Excel, paste. It can copy just the top line or every line in the band. If a line has no value, you're told and the clipboard is left alone, so you never paste the previous line's number by mistake.
- **Rightmost value on the line** is now the default: Value Grab takes whatever number sits furthest right, usually the line total. Choose **Rightmost dollar amount** in Settings to only take numbers written as money.
- **Better numbers from scans:** Value Grab repairs common OCR slips before reading a number, such as a stray space (`425. 00`), the letter O or l in place of 0 or 1 (`1O5.5O`), a split-off `$`, or a trailing speck. Before, a garbled total could make it fall back to a number in the middle of the line.
